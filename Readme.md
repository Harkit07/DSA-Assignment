# Java DSA Practice

A collection of Java programs for completing the Data Structures and Algorithms assignments from the Apna College batch. Each source file focuses on a Java concept, data structure, algorithm, or problem-solving pattern.

## About

This repository is organized as standalone Java classes, so individual topics can be compiled and run independently. The goal is to complete all assigned work in one place while strengthening Java and DSA fundamentals through regular practice.

## Tech Stack

- **Language:** Java
- **Tools:** VS Code, Git, and GitHub

## How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/Harkit07/DSA-Assignment.git
   cd DSA-Assignment
   ```

2. Compile a Java file:

   ```bash
   javac FileName.java
   ```

3. Run the class without the `.java` extension:

   ```bash
   java FileName
   ```

For example:

```bash
javac VariableAndDataType.java
java VariableAndDataType
```
